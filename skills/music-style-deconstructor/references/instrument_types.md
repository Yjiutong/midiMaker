# 乐器类型知识库（Instrument Types，只给类型）

> 用途：`instrument_map.py` 据此把每轨标注为**乐器类型**（不指定具体 VST / 硬件型号，由你在 FL Studio 中自选插件）。  
>     选择依据：音区、奏法、genre、以及（若提供）作者风格指纹的惯用配置。

## 通用分层类型表

| 编曲层 | 常见类型（只标注这些） |
| --- | --- |
| 主旋律 (Melody Lead) | 合成主音 Lead / 原声钢琴 / 电吉他 / 弦乐独奏 / 木管 / 方波 Lead / 人声同度叠奏 |
| 和声·Pad (Chords/Pad) | 暖色 Pad / 弦乐铺底 / 电子 Pad / 原声吉他扫弦 / 电钢琴 / 风琴 / 合成铺底 |
| 贝斯 (Bass) | 合成贝斯 / 电贝斯 / 原声贝斯 / 八度贝斯 / 滑音贝斯 / 拨片贝斯 |
| 鼓组 (Drums) | 原声鼓组 / 电子鼓(808) / 采样碎拍 / 工业鼓 / 爵士鼓 / 拉丁打击 |
| 人声 (Vocal, ref) | 见 `sv_voicebank.md`（SV 声库类型，非传统乐器） |

## 按 Genre 的推荐搭配（类型组合）

### Pop（流行）

- 主旋律：合成主音 Lead 或 原声钢琴

- 和声：暖色 Pad + 弦乐铺底

- 贝斯：电贝斯 / 合成贝斯

- 鼓：原声鼓组（或轻度电子）

### R\&B / Soul

- 主旋律：电钢琴旋律 / 弦乐独奏

- 和声：暖色 Pad + 电钢琴

- 贝斯：滑音贝斯 / 电贝斯

- 鼓：原声鼓组 + 大量 ghost note

### Hip-Hop / Trap

- 主旋律：方波 Lead / 合成主音

- 和声：电子 Pad

- 贝斯：808 合成贝斯（滑音）

- 鼓：电子鼓(808) + 碎拍 hi-hat

### EDM / Electronic

- 主旋律：合成主音 Lead / 方波

- 和声：电子 Pad / 合成铺底

- 贝斯：合成贝斯 / 八度贝斯

- 鼓：电子鼓 / 工业鼓

### Rock

- 主旋律：电吉他（失真）/ 人声同度

- 和声：电吉他扫弦 / 风琴

- 贝斯：电贝斯 / 拨片贝斯

- 鼓：原声鼓组（驱动）

### Singer-Songwriter（创作歌手）

- 主旋律：人声（SV）+ 原声钢琴 叠奏

- 和声：原声吉他扫弦 / 暖色 Pad

- 贝斯：原声贝斯 / 电贝斯

- 鼓：原声鼓组（克制）

### Jazz

- 主旋律：原声钢琴 / 萨克斯 / 小号

- 和声：原声钢琴 / 风琴

- 贝斯：原声贝斯（walking）

- 鼓：爵士鼓（brush 感）

### Lo-fi

- 主旋律：电钢琴 / 暖色 Pad

- 和声：暖色 Pad + 弦乐铺底（模糊）

- 贝斯：电贝斯

- 鼓：采样碎拍（带噪声）

### J-Pop / 动漫（常用于 SV 人声）

- 主旋律：合成主音 Lead / 原声钢琴

- 和声：弦乐铺底 + 电子 Pad

- 贝斯：电贝斯 / 合成贝斯

- 鼓：原声鼓组 + 电子元素

### C-Pop / 华语流行（常用于 SV 人声）

- 主旋律：合成主音 Lead / 原声钢琴

- 和声：暖色 Pad + 弦乐铺底

- 贝斯：电贝斯

- 鼓：原声鼓组

## 标注输出格式（instrument_map.py）

```markdown
| 轨 | MIDI 通道 | 乐器类型 | 推荐奏法 / 备注 |
|---|---|---|---|
| 主旋律 | 1 | 合成主音 Lead | 连奏，叠加人声同度 |
| 和声·Pad | 2 | 暖色 Pad | 长音铺底，低通 |
| 贝斯 | 3 | 电贝斯 | 八分音符律动 |
| 鼓组 | 10 | 原声鼓组 | kick+snare+hat |
| 人声(ref) | 5 | SV 声库（见 sv_recommendation.md） | 参考唱线，导入 SV |
```

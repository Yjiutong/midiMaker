# Synthesizer V 声库类型推荐与导入指南

> 用途：`vocal_track_sv.py` 只输出**声库类型**（日系/中系/英系、男/女、音域），不绑定具体声库商品。  
>     你可在 Synthesizer V（SV2）中按类型自选声库，并用人声参考包完成填词与演唱。

## 一、声库类型分类（按风格 / 性别 / 音域）

| 类型 | 适用风格 | 性别 | 典型音域 | 备注 |
| --- | --- | --- | --- | --- |
| 日系女声（清澈） | J-Pop / 动漫 / City Pop | 女 | 中高 | 亮、通透，适合主歌副歌 |
| 日系女声（低沉/气声） | 抒情 / R\&B | 女 | 中 | 气声多，贴耳 |
| 日系男声（少年/中性） | 动漫 / 轻摇滚 | 男 | 中 | 偏薄，年轻感 |
| 日系男声（成熟） | 摇滚 / 叙事 | 男 | 中低 | 厚实，有力度 |
| 中系女声（甜美） | C-Pop / 古风 | 女 | 中高 | 甜、亮 |
| 中系女声（伤感/气声） | 抒情 / 民谣 | 女 | 中 | 气声、弱混 |
| 中系男声 | C-Pop / 说唱 | 男 | 中低 | 自然、叙事 |
| 英系/韩系女声 | EDM / 欧美流行 | 女 | 中高 | 力量、共鸣 |
| 英系/韩系男声 | 欧美流行 / R\&B | 男 | 中低 | 胸声为主 |
| 特殊/虚拟感声线 | 电子 / 实验 | 不限 | 宽 | 合成感、机器人感 |

> 选择依据：`vocal_track_sv.py` 从 `vocals` stem 提音高线，统计**音域（最低/最高 MIDI）、平均音高、动态范围**，再按上表匹配最贴合的类型。

## 二、人声参考包内容（vocal/ 目录）

- `vocal_melody.mid`：**主旋律音高线**（含基本节奏格子），仅作 SV 中的参考唱线（参考 Pitch + 节奏），不含歌词。

- `lyrics_placeholder.txt`：按乐句切分的歌词占位，每个音符对应一个 `[歌词]` 占位与音节位置，你替换成实际歌词。

- `sv_recommendation.md`：推荐声库类型 + 导入流程。

## 三、SV 导入流程（在 Synthesizer V 中）

1. 打开 Synthesizer V，新建工程，选择**匹配类型的 AI 声库**。

2. 导入参考：`vocal_melody.mid`（文件 → 导入 → MIDI），作为**参考唱线**；或手动照着画 Pitch。

3. 把 `lyrics_placeholder.txt` 的乐句填入对应音符（SV 中选中音符 → 输入拼音/假名/汉字，SV 自动转音素）。

4. 对齐节奏：按参考唱线调整每个音符的起止与连线（legato），处理气声/滑音（用 Pitch 编辑与 breath/transition 参数）。

5. 试听微调：调节 气息(Air)、张力(Strength)、情感参数，直到自然。

6. 渲染人声为音频（WAV），回到 FL Studio 作为音频轨与人声 MIDI 参考轨对齐（MIDI 参考轨可静音或删除）。

## 四、注意事项

- 自动提取的音高线**不含咬字、气声、颤音细节**，仅锚定音高与节奏骨架。

- 若原曲人声有大量滑音 / 转音，参考唱线可能「阶梯化」，需在 SV 中手动补滑音（Pitch 曲线）。

- 多人和声 / 叠唱：当前只提取主旋律线；若需和声，可在 SV 中复制声部并移调。

- 歌词占位文本中的音节数应大致匹配音符数，避免一字多音或一音多字导致 SV 渲染异常。
